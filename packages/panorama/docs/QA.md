# Проверка поставки 1.0.0

Дата: 8 октября 2026 года. Окружение: macOS, Node.js 22+, локальный Chrome через Playwright. Проверялась сборка пакета, отдельно от лаборатории.

## Выполнено

- `npm run build`: самостоятельный JS, React ESM, декларации TypeScript, CSS и шрифты собраны.
- `npm test`: независимость конфигураций, сериализация, отклонение неверных данных; Sharp — предел 1600 px, заглушка 96 px, прозрачность, ориентация EXIF, отсутствие увеличения малых фото.
- `PANORAMA_BROWSER_CHANNEL=chrome npm run test:browser`: пустая страница; пакетная загрузка и сжатие; текст со стилем; сохранение черновика после перезагрузки; публикация; два независимых экземпляра с одинаковыми ID материалов; перетаскивание и подсказки; галерея, Tab, Escape, возврат фокуса и прокрутки; удаление открытого экземпляра; отложенная загрузка; видео с постером; замена фото; недоступный файл галереи; мобильная ширина 390 px и reduced motion. Ошибок JavaScript нет.
- `examples/next`: production-сборка и предварительный рендер Next.js 15.5.27; в браузере — гидратация, загрузка, сохранение и публикация без ошибок JavaScript.
- Проверены зависимости пакета и примера Next.js: `npm audit` не обнаружил известных уязвимостей на дату проверки.

Браузерные тесты создают одноцветные изображения и короткое видео во временной папке. В поставке нет стартовых медиа. После своего запуска тест сохраняет отчёт в `artifacts/browser-report.json`.

## Границы проверки

Сайты и настоящие CMS не изменялись. Не проверены Safari, Firefox, реальные iOS/Android, PHP-обработчики и production-авторизация команд сайтов. Мобильная проверка выполнена в Chrome с размером окна 390 × 844; это не проверка физического телефона. Видео не перекодируется: воспроизведение зависит от формата и браузера. Встроенный сервер — локальный пример, не готовый production-бэкенд.

## Перед включением на сайте

Подключить адаптер к своей CMS; проверить сохранение каждого блока, права и конкурентное редактирование средствами CMS. На целевой странице проверить стили, шрифты, вертикальную прокрутку и галерею на поддерживаемых устройствах, включая ширины 320, 599 и 600 px. Проверить реальные фото/видео и работу загрузки при ошибке сети.
