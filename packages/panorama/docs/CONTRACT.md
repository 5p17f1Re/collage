# Конфигурация добавленного блока

Реализована в [пакете Панорамы](../README.md). У каждого блока страницы — свой `blockId` и полная конфигурация `PanoramaData`: `schemaVersion: 1`, `items`, `seed`, `settings`. Настройки Панорамы, фон и сетка сохраняются внутри этой конфигурации вместе со списком материалов. Правка одного блока не перезаписывает другой. Временное положение после жеста и открытая галерея не сохраняются.

Сайт хранит конфигурацию в своей записи блока. Черновик и опубликованная версия содержат полные снимки. Публичный компонент читает опубликованный снимок; редактор получает черновик через `initialData`. Связь с коллекциями, повторное использование материалов и структура CMS остаются решениями сайта. На странице поддерживаются ноль, один или несколько экземпляров.

## Готовый интерфейс

```js
const a = AvgvstPanorama.mountPanorama(containerA, dataA);
const b = AvgvstPanorama.mountPanorama(containerB, dataB);
a.update(updatedDataA);
b.destroy();

const editor = AvgvstPanorama.mountEditor(adminContainer, {
  blockId: 'block-42', initialData: draft, adapter: siteAdapter
});
```

Код/CSS/шрифты подключаются один раз. Экземпляры имеют собственные жесты, галерею и настройки. В React доступны `Panorama` и `PanoramaEditor`. Поля, значения по умолчанию, примеры и типы описаны в [README](../README.md).

## Что реализует адаптер сайта

| Метод | Обязанность |
|---|---|
| `uploadMedia(prepared, { blockId, signal })` | Сохранить уже сжатые файлы, заглушку и постер видео; вернуть постоянные `source`, `placeholder`, `poster`. |
| `saveDraft(blockId, data, { signal })` | Сохранить полный черновик этого блока. |
| `publish(blockId, data, { signal })` | Опубликовать именно переданный снимок целиком. |

Все изображения редактор сжимает до передачи адаптеру. Текст и стиль текстовой карточки находятся в `items`. Сохранение после перезагрузки обеспечивается бэкендом сайта. Пример работающего адаптера с локальным хранением поставляется в пакете; production-авторизация и интеграция с настоящей CMS выполняются командами сайтов.
