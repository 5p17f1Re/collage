# Подготовка и упаковка Панорамы

**8 октября 2026 года. Выполнено в пакете `packages/panorama/`, версия 1.0.0.**

## Что подготовлено

- Самостоятельный JS для HTML/jQuery/PHP и React-сборка с TypeScript-типами для Next.js.
- Публичная Панорама и редактор: фото, видео, текст со стилем, подписи, порядок, главный материал, настройки, предпросмотр, черновик и публикация.
- Независимые экземпляры: конфигурация каждого блока содержит материалы, seed и настройки. Общие JS/CSS/шрифты подключаются один раз.
- Обработка каждого добавленного и заменённого изображения, заглушки, постеры видео; отдельная утилита Sharp для серверных импортов.
- Подгрузка по близости к экрану, изолированные стили, очистка экземпляра, галерея с клавиатурой и обработкой недоступного файла.
- Рабочие HTML- и Next.js-примеры с локальным сохранением через адаптер. Стартовых изображений нет.

## Повторить сборку и упаковку

В папке пакета, Node.js 22.12+:

```sh
npm ci
npm run build
npm test
npm run pack:handoff
```

Браузерные проверки: `npx playwright install chromium`, затем `npm run test:browser`. При установленном Chrome: `PANORAMA_BROWSER_CHANNEL=chrome npm run test:browser`.

В `artifacts/` появятся ZIP передачи и npm-архив. ZIP содержит готовый `dist/`, исходники, скрипты, тесты, примеры, закреплённые зависимости, документацию и лицензии. Локальные загрузки, node_modules и тестовые фотографии исключены. Параметры обработки и интерфейс адаптера описаны в README.

## Что подключает команда сайта

Три операции: загрузка подготовленных файлов, сохранение черновика и публикация полного снимка блока. Команда использует свои хранение, права доступа, проверку файлов и CMS; добавляет блок и редактор в существующие страницы. Российскому production-серверу Node.js не требуется. Локальный сервер примера не предназначен для production.

Результаты проверок и границы приёмки — в QA.md пакета. Интеграция в настоящие админки и проверка на целевых устройствах выполняются командами сайтов.
