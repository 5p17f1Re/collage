# Панорама — спецификация для встройки

**Обновлено 8 октября 2026 года.** Документ описывает поставляемую Панораму. Готовый пакет находится в [packages/panorama](packages/panorama/README.md); лаборатория в корневой папке остаётся отдельным прототипом. Пакет не содержит тестовых материалов. Сохранение в CMS подключается через адаптер сайта.

## 1. Блок на странице и редактор

Администратор создаёт или открывает страницу, добавляет блок коллажа, загружает несколько фото/видео, добавляет текстовые карточки и подписи, настраивает композицию. Нужны сохранение черновика, предпросмотр и публикация. Откат не требуется. Покупатель рассматривает Панораму и открывает медиа крупнее; инструменты редактирования ему недоступны.

На странице может быть ноль, один или несколько коллажей. Код и стили подключаются один раз; каждый экземпляр получает собственные материалы, настройки и состояние взаимодействия. Возможность использовать один коллаж на нескольких страницах не ограничиваем. Связь страниц и коллажей определяет команда сайта — ID коллекции не является обязательным входом компонента.

Новые материалы добавляются к существующим и смешиваются с ними в общей композиции; первый элемент остаётся главным. Ручное размещение каждого кадра и отдельные механики глав не нужны. Черновик не изменяет опубликованный блок до публикации.

## 2. Композиция, размеры, адаптив, медиазапросы

Первый элемент списка — центральный якорь. Остальные карточки размещаются автоматически без перекрытий. При недостатке места алгоритм уменьшает вторичные карточки. Порядок списка не задаёт расстояние от центра. Раскладка воспроизводится по материалам, настройкам, `seed` и размерам контейнера.

| Параметр | Текущее значение |
|---|---|
| Ширина блока | Ширина его контейнера; размер измеряется через `ResizeObserver` |
| Экран от 600 px | Сцена 880 px; полоса размещения 720 px; вертикальное перемещение ±80 px |
| Экран до 599 px | Сцена 85dvh внутри области 100dvh, по 7.5dvh сверху и снизу; движение только по горизонтали |
| Ширина циклической ленты | 50–250% с шагом 5%, по умолчанию 100%: соответственно 1–5 ширин сцены, по умолчанию две |
| Размер главного кадра | 50–250% с шагом 5%, по умолчанию 150%; ограничен доступным местом |
| Зазор между карточками | 0 / 4 / 8 / 12 / 16 px; по умолчанию 4 px |
| Размерные группы | 1–7, по умолчанию 3; назначение автоматически или вручную для карточки |
| Контраст размеров | 0–250% с шагом 5%, по умолчанию 60%; малые группы уменьшаются относительно крупных, после изменения упаковка заполняет освободившееся место |
| Фон и сетка | Белый фон, сетка выключена; цвет точек `#4A4A4A` |

Мобильный порог задаётся `@media (max-width: 599px)` в CSS и таким же `matchMedia` в приложении. `touch-action: pan-y` оставляет вертикальную прокрутку страницы браузеру. `prefers-reduced-motion: reduce` отключает пространственные анимации и докат. Пропорции медиа сохраняются, используется `object-fit: contain`.

При ленте до 1,7 экрана с текстовыми карточками упаковка может сравнить два независимых порядка размещения, если исходный порядок занимает менее 75% центральной полосы. Текст резервирует место раньше изображений; выбирается вариант с большей занятой площадью. Это предотвращает чрезмерное уменьшение всех изображений из-за поздно размещённого текста. Верхние и нижние 80 px десктопной сцены относятся к вертикальному перемещению и не входят в расчёт заполнения.

Исходники: [геометрия и упаковка](packages/panorama/src/lib/layout.ts), [измерение сцены и рендер](packages/panorama/src/components/CollageStage.tsx), [CSS: `.collage-stage--panorama`](packages/panorama/src/rendering.css). Размеры выше относятся к сцене; оформление остальной страницы в поставку блока не входит.

## 3. Жесты и анимация

Перетаскивание реализовано **GSAP 3.14 + Draggable**. Лента отрисовывается в трёх копиях, координата X нормализуется при пересечении стыка. Это создаёт непрерывное горизонтальное движение.

Докат после жеста написан поверх Draggable, без InertiaPlugin: из выборок последних 110 ms вычисляется скорость, ограниченная ±1600 px/s по X и ±900 px/s по Y. Ниже 70 px/s докат не запускается. При энергии `e` от 0 до 100 длительность равна `0.15 + (e / 100) * 1.2` секунды, смещение — скорость × длительность / 2. Горизонтальный предел — `min(0.65 × ширина ленты, 760 px)`, вертикальный — границы сцены. `gsap.to` с `power2.out` анимирует промежуточные координаты, `onUpdate` переносит их в transform полотна через `gsap.set`. Новый жест останавливает tween. Энергия 0 и reduced motion выключают докат; по умолчанию энергия 40.

При первом появлении главный материал показывается первым, остальные — по расстоянию от него: fade 160 ms, подъём на 20 px за 480 ms, интервал 27.5 ms. Подсказка у краёв сдвигает полотно на 20 px и исчезает после первого перетаскивания. В пакете зоны считаются от 10% ширины контейнера конкретного экземпляра; события соседних блоков на него не влияют.

Исходники: [Draggable, `onDragEnd`, обработчики краёв](packages/panorama/src/components/CollageStage.tsx), [spring-кривая](packages/panorama/src/lib/motion.ts), [анимации карточек](packages/panorama/src/rendering.css).

## 4. Текстовые карточки и их стили

Текст — такой же элемент списка материалов: `type: "text"`, `text`, `textStyle`. Стиль хранится **в самой карточке**, значения — `gramatika` и `wremena`. Текстовые карточки не открывают галерею.

Правила находятся в [стилях рендера](packages/panorama/src/rendering.css); сборка добавляет к селекторам `.avgvst-panorama` и дополняет их [стилями оболочки](packages/panorama/src/shell.css). В исходнике: `@font-face` в начале файла, далее `.collage-card--text`. Основные значения:

```css
@font-face {
  font-family: AvgvstPanoramaGramatika;
  src: url('./assets/fonts/Gramatika-Regular.ttf') format('truetype');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: AvgvstPanoramaWremena;
  src: url('./assets/fonts/Wremena-Regular.otf') format('opentype');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}
.collage-card--text { padding: 4px; background: oklch(1 0 0); }
.collage-card--text p {
  margin: 0;
  color: oklch(0.12 0 0);
  font-family: AvgvstPanoramaGramatika, sans-serif;
  font-size: 14px;
  font-weight: 400;
  line-height: 16px;
  text-align: left;
  white-space: pre-wrap;
  overflow-wrap: anywhere;
  word-break: normal;
}
.collage-card--text[data-text-style="wremena"] p {
  font-family: AvgvstPanoramaWremena, serif;
  font-size: 15.5px;
}
```

Файлы гарнитур: [Gramatika](packages/panorama/src/assets/fonts/Gramatika-Regular.ttf), [Wremena](packages/panorama/src/assets/fonts/Wremena-Regular.otf). Пути шрифтов в готовом `dist/styles.css` ведут в `dist/assets/fonts/`. Мобильные правила находятся в `src/shell.css`.

[Измерение текста](packages/panorama/src/lib/textCardMetrics.ts) ждёт `document.fonts.load` и `document.fonts.ready`, затем измеряет карточку с этими же параметрами. Ширина подбирается от 232 до 320 px с шагом 2 px, ориентир — четыре строки; длинный текст увеличивает высоту. Размеры шрифтов, интерлиньяж и padding сейчас продублированы в CSS и измерителе: при правке типографики менять оба места, иначе расчёт раскладки разойдётся с отображением.

## 5. Медиа: сжатие, адреса и подгрузка

Каждый экземпляр получает свой `items`. `source` — постоянный адрес основного файла, `placeholder` — заглушки, `poster` — постера видео, `aspectRatio` — пропорции. В сохранённой конфигурации `blob:` и `data:` не допускаются. [Поля и проверка](packages/panorama/src/config.ts).

| Что | Реализация пакета |
|---|---|
| Любое добавление или замена фото | [prepareMedia](packages/panorama/src/media.ts) декодирует JPEG/PNG/WebP/AVIF с учётом поворота, сохраняет прозрачность, создаёт WebP до 1600 px без увеличения, quality 0.88. Заглушка: до 96 px, blur 1.4, quality 0.42. Затем передаёт подготовленные файлы адаптеру загрузки. |
| Серверный импорт изображений | [optimizeImage на Sharp](packages/panorama/scripts/optimize-image.mjs) возвращает основной файл, заглушку и размеры с теми же параметрами. Можно использовать для импортов в обход редактора. Повторное пережатие уже подготовленных файлов не требуется. |
| Видео | Браузер извлекает постер до 640 px, quality 0.82, и заглушку до 96 px, quality 0.42. Видео не перекодируется. При ошибке декодирования или ожидании дольше 10 s загрузка сообщает об ошибке. |
| Изображения на странице | [ImageWithPlaceholder](packages/panorama/src/components/ImageWithPlaceholder.tsx) назначает `src` при приближении к экрану, до загрузки показывает заглушку, затем основной кадр проявляется за 240 ms. Выбранный кадр галереи загружается сразу. |
| Блоки ниже экрана | [Panorama](packages/panorama/src/Panorama.tsx) сохраняет размер пустой сцены и монтирует содержимое при приближении к экрану. Порог observer — 300 px. |
| Видео на странице | [VisibilityVideo](packages/panorama/src/components/VisibilityVideo.tsx): загрузка по приближению, `muted`, `loop`, `playsInline`; воспроизведение при видимости ≥15% и видимой вкладке. Видео Панорамы приостанавливаются при открытии её галереи. В Панораме `preload="none"`, в галерее `metadata`. |

Сжатие применяется ко всем загрузкам редактора, включая пакетные добавления и замену. Файлы сохраняет адаптер сайта и возвращает постоянные URL. SVG/GIF/HEIC требуют предварительного преобразования; неподдерживаемый файл не выдаётся за успешно загруженный. Пустой список не подставляет демонстрационные картинки. Сервер сайта обязан валидировать загружаемые файлы и права самостоятельно.

## 6. Галерея

Клик открывает вертикальный список фото/видео **этого экземпляра**. Активное медиа целиком помещается в 80% ширины и высоты окна. Строка — `90dvh + 8px`, вертикальные отступы 8 px. Подложка: `#F2F2F3` с непрозрачностью 55%, blur 5 px, насыщенность 80%.

GSAP открывает кадр из реальных границ нажатой карточки за 0.425 s по spring-кривой из [motion.ts](packages/panorama/src/lib/motion.ts); соседние кадры въезжают за 0.42 s. Закрытие за 0.252 s возвращает кадр к **тому же DOM-экземпляру**, в том числе после прокрутки галереи. Закрыть можно крестиком, Escape, фоном или медиа. При reduced motion или недоступном источнике используется затухание. Переход начинается после готовности активного медиа.

Исходники: [GalleryDialog.tsx](packages/panorama/src/components/GalleryDialog.tsx), [CSS: `.gallery` и дочерние селекторы](packages/panorama/src/rendering.css).
