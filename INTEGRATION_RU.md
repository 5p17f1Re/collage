# Передача российской команде

Стек: HTML, CSS, JavaScript, jQuery; PHP 7.3. Готовый пакет и инструкция: [packages/panorama/README.md](packages/panorama/README.md).

1. Разместить `dist/` в ресурсах сайта, подключить `styles.css` и `panorama.js` один раз. React/ReactDOM/GSAP уже включены в JS; Node.js на PHP-сервере не нужен.
2. Для каждого блока страницы вызвать `AvgvstPanorama.mountPanorama(container, data)`. Для редактора в админке — `mountEditor(container, { blockId, initialData, adapter })`.
3. Подключить три операции адаптера: сохранение подготовленных медиа, черновика и публикации. Хранить материалы и настройки в конфигурации конкретного блока.

Сжатие всех фото, подготовка превью, независимые экземпляры и галерея реализованы в пакете. Способ хранения, production-права и поля CMS определяет команда сайта. Рабочий локальный пример находится в `examples/html/`; его сервер предназначен для проверки интеграции, не для публикации в production. Полный сценарий запуска и API — в README пакета.
